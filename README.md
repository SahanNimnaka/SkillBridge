# SkillBridge

SkillBridge is an AI-powered internship opportunity matching platform designed for Sri Lankan university students and fresh graduates.

It helps candidates discover relevant internships, understand how their skills compare with job requirements, identify qualification gaps, and receive actionable recommendations.

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- ESLint
- Git and GitHub

Planned technologies include PostgreSQL, Prisma ORM, and an LLM API.

## Prerequisites

- Node.js 20.9 or later
- npm
- Git

## Getting Started

Clone the repository or open the project directory.

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Commands

```bash
npm run dev
npm run build
npm run start
npm run lint
```

- `dev` starts the development server.
- `build` creates a production build.
- `start` runs the production server after building.
- `lint` checks code quality.

- Do not commit API keys, passwords, or database credentials.
- Keep secrets in local environment files.
- Validate user input and protect private user data.
