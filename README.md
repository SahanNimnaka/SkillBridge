# SkillBridge

SkillBridge is an AI-powered internship opportunity matching platform designed for Sri Lankan university students and fresh graduates.

It helps candidates discover relevant internships, understand how their skills compare with job requirements, identify qualification gaps, and receive actionable recommendations.

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- ESLint
- Git and GitHub

**Planned technologies:** PostgreSQL, Prisma ORM, and an LLM API.

## Prerequisites

- Node.js 20.9 or later
- npm
- Git

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open the application

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Available Commands

| Command         | Description                               |
| --------------- | ----------------------------------------- |
| `npm run dev`   | Starts the development server             |
| `npm run build` | Creates a production build                |
| `npm run start` | Runs the production server after building |
| `npm run lint`  | Checks code quality                       |

## Project Status

SkillBridge is under active development. Features and integrations will be implemented incrementally based on the project requirements.

- Never commit API keys, passwords, or database credentials.
- Store secrets in local environment files.
- Validate user input and protect private user data.
